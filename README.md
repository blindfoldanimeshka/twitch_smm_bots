# Twitch Bot Farm - Система управления ботами для стримов

**Статус:** ✅ Полностью готов к использованию

## Что это такое?

Это программа для автоматического управления ботами в чате Twitch. Боты подключаются к каналу стримера и пишут сообщения, которые генерирует искусственный интеллект. Это помогает начинающим стримерам создать видимость активного чата.

**Простыми словами:** У вас есть Twitch канал → вы запускаете эту программу → боты начинают писать в ваш чат реалистичные сообщения → ваш канал выглядит живым и активным.

## Что умеет программа?

### Основные возможности

- 🤖 **Управление ботами** - запускать, останавливать, настраивать ботов
- 🌐 **Веб-панель** - красивый интерфейс для управления (не нужно лезть в консоль)
- 🧠 **Искусственный интеллект** - боты пишут реалистичные сообщения через AI
- 🎭 **4 типа личностей** - веселый фанат, токсик, нейтрал, хайпер
- 🔄 **Real-time обновления** - статус ботов обновляется мгновенно
- 🛡️ **Защита от банов** - прокси-серверы и ограничения частоты сообщений
- 📊 **Статистика** - сколько ботов работает, сколько сообщений отправлено

### Технические фишки

- REST API для интеграций
- WebSocket для мгновенных обновлений
- Redis для кэширования
- PostgreSQL для хранения настроек
- Docker для простого запуска
- Поддержка любых AI провайдеров (локальные и облачные)

## Быстрый старт (5 шагов)

### Шаг 1: Установить Docker

Docker нужен для базы данных. Скачать: https://www.docker.com/products/docker-desktop/

После установки проверить:
```bash
docker --version
```

### Шаг 2: Запустить базу данных

Открыть терминал в папке проекта и выполнить:

```bash
docker compose up -d
```

Это запустит PostgreSQL (база данных) и Redis (кэш). Проверить что запустилось:

```bash
docker ps
```

Должны быть 3 контейнера: postgres, redis, pgadmin.

### Шаг 3: Настроить AI (выбрать один вариант)

**Вариант A: Локальный AI (бесплатно, но нужен мощный компьютер)**

1. Скачать LM Studio: https://lmstudio.ai/
2. Открыть LM Studio
3. Скачать модель (например, Llama 3 или Mistral)
4. Нажать "Start Server" на порту 1234

Настроить переменные:
```bash
export LLM_PROVIDER="lmstudio"
export LLM_API_URL="http://127.0.0.1:1234/v1"
export LLM_MODEL="local-model"
```

**Вариант B: Облачный AI (платно, но не нужен мощный компьютер)**

Рекомендую Omniroute - там много провайдеров через один API.

1. Зарегистрироваться на https://omniroute.ai/
2. Получить API ключ
3. Настроить переменные:

```bash
export LLM_PROVIDER="omniroute"
export LLM_API_URL="https://omniroute.ai/v1"
export LLM_MODEL="gpt-4o-mini"
export LLM_API_KEY="ваш-ключ-от-omniroute"
```

**Популярные модели в Omniroute:**
- `gpt-4o-mini` - быстро и дешево (OpenAI)
- `claude-3-5-sonnet-20241022` - очень качественно (Anthropic)
- `gemini-2.0-flash-exp` - бесплатно (Google)

### Шаг 4: Создать ботов

Нужно добавить ботов в базу данных. Для каждого бота нужен:
- Twitch аккаунт (логин)
- OAuth токен (пароль для бота)

**Как получить OAuth токен:**
1. Зайти на https://twitchapps.com/tmi/
2. Авторизоваться через Twitch
3. Скопировать токен (выглядит как `oauth:abcd1234...`)

**Добавить ботов через pgAdmin:**

1. Открыть http://localhost:5050
2. Войти:
   - Email: `admin@local.dev`
   - Password: `admin`
3. Подключиться к серверу:
   - Host: `postgres`
   - Port: `5432`
   - Database: `twitch_bot_farm`
   - Username: `botfarm`
   - Password: `botfarm`
4. Открыть Query Tool и выполнить:

```sql
INSERT INTO bots (id, twitch_login, oauth_token, name, personality, min_delay_sec, max_delay_sec, rate_limit_per_min, enabled)
VALUES 
    ('bot1', 'ваш_логин_бота_1', 'oauth:ваш_токен_1', 'Алекс', 'веселый_фанат', 45, 180, 10, TRUE),
    ('bot2', 'ваш_логин_бота_2', 'oauth:ваш_токен_2', 'Макс', 'токсик', 60, 200, 8, TRUE),
    ('bot3', 'ваш_логин_бота_3', 'oauth:ваш_токен_3', 'Аня', 'нейтрал', 40, 150, 12, TRUE);
```

**Что означают параметры:**
- `id` - уникальное имя бота (любое)
- `twitch_login` - логин Twitch аккаунта
- `oauth_token` - токен от twitchapps.com
- `name` - отображаемое имя
- `personality` - тип личности (веселый_фанат, токсик, нейтрал, хайпер)
- `min_delay_sec` - минимальная задержка между сообщениями (секунды)
- `max_delay_sec` - максимальная задержка
- `rate_limit_per_min` - максимум сообщений в минуту
- `enabled` - TRUE = бот включен, FALSE = выключен

### Шаг 5: Запустить программу

**Настроить обязательные переменные:**

```bash
# Канал куда боты будут писать
export TWITCH_CHANNEL="имя_вашего_канала"

# Ключ для доступа к веб-панели (придумайте любой)
export API_KEY="мой-секретный-ключ-12345"
```

**Запустить backend (сервер):**

```bash
go run logic.go
```

Должно появиться:
```
LLM API OK (provider: omniroute, url: https://omniroute.ai/v1, model: gpt-4o-mini)
Redis OK (redis://localhost:6379)
API server starting on :8080
```

**Запустить frontend (веб-панель):**

Открыть новый терминал и выполнить:

```bash
cd frontend
npm install  # только первый раз
npm run dev
```

Откроется веб-панель: http://localhost:5173

**Настроить frontend:**

Создать файл `frontend/.env`:
```
VITE_API_URL=http://localhost:8080
VITE_WS_URL=ws://localhost:8080
VITE_API_KEY=мой-секретный-ключ-12345
```

(API_KEY должен совпадать с тем, что вы указали в backend)

## Как пользоваться веб-панелью

Откройте http://localhost:5173 - увидите:

### Дашборд (верхняя часть)
- **Total Bots** - сколько всего ботов
- **Running Bots** - сколько сейчас работает
- **Messages/Min** - сколько сообщений в минуту
- **WebSocket** - подключение к серверу (зеленый = ОК)

### Управление ботами
Каждый бот показан в виде карточки:
- **Зеленая карточка** = бот работает
- **Белая карточка** = бот остановлен

**Кнопки:**
- **Start** - запустить бота (начнет писать в чат)
- **Stop** - остановить бота
- **Delete** - удалить бота из системы

**Кнопки сверху:**
- **Start All** - запустить всех ботов сразу
- **Stop All** - остановить всех

### Real-time обновления

Когда бот отправляет сообщение, вы сразу увидите это в веб-панели (не нужно обновлять страницу).

## Типы личностей ботов

### Веселый фанат
Пишет позитивные комментарии:
- "Крутой момент!"
- "Ты лучший!"
- "Обожаю этот стрим"

### Токсик
Провоцирует дискуссии (но не оскорбляет):
- "А почему так сделал?"
- "Это была ошибка"
- "Можно было лучше"

### Нейтрал
Обычные вопросы и комментарии:
- "Какая игра?"
- "Сколько играешь?"
- "Интересно"

### Хайпер
Энергичные сообщения со сленгом:
- "Вау! Топчик!"
- "Го еще!"
- "Жесть!"

## Консольное управление (альтернатива веб-панели)

Если не хотите использовать веб-панель, можно управлять через консоль:

```
> list              # Показать всех ботов
> start bot1        # Запустить бота bot1
> stop bot1         # Остановить бота bot1
> start-all         # Запустить всех
> stop-all          # Остановить всех
> quit              # Выход
```

## Прокси-серверы (защита от банов)

Twitch может забанить ботов если они все с одного IP. Чтобы этого избежать, используйте прокси.

### Добавить прокси через API

```bash
curl -X POST -H "X-API-Key: ваш-ключ" \
  -H "Content-Type: application/json" \
  -d '{"id":"proxy1","host":"proxy.example.com","port":8080,"protocol":"http"}' \
  http://localhost:8080/api/proxies
```

### Назначить прокси боту

Через SQL:
```sql
UPDATE bots SET proxy_id = 'proxy1' WHERE id = 'bot1';
```

Или включить автоматическую ротацию:
```sql
UPDATE bots SET auto_rotate_proxy = TRUE WHERE id = 'bot1';
```

## Решение проблем

### Backend не запускается

**Ошибка:** `LLM API is not reachable`
- Проверьте что LM Studio запущен (если используете локально)
- Проверьте API ключ (если используете облако)
- Проверьте интернет соединение

**Ошибка:** `postgres connect error`
- Проверьте что Docker запущен: `docker ps`
- Перезапустите контейнеры: `docker compose restart`

**Ошибка:** `TWITCH_CHANNEL is required`
- Установите переменную: `export TWITCH_CHANNEL="ваш_канал"`

### Frontend не подключается

**Ошибка:** `Network Error`
- Проверьте что backend запущен (должен быть на порту 8080)
- Проверьте файл `frontend/.env` - там должен быть правильный API_KEY

**WebSocket показывает "Disconnected"**
- Проверьте что backend запущен
- Проверьте что в `frontend/.env` правильный `VITE_API_KEY`

### Боты не пишут в чат

**Проблема:** Боты запущены но не пишут
- Проверьте OAuth токены в базе данных (может истекли)
- Проверьте что AI провайдер отвечает
- Посмотрите логи backend - там будут ошибки

**Проблема:** "Twitch send error"
- OAuth токен неправильный или истек
- Получите новый токен на https://twitchapps.com/tmi/

## API для разработчиков

Если хотите интегрировать с другими программами, используйте REST API.

**Все запросы требуют заголовок:**
```
X-API-Key: ваш-секретный-ключ
```

### Основные endpoints

```bash
# Получить список ботов
GET http://localhost:8080/api/bots

# Запустить бота
POST http://localhost:8080/api/bots/bot1/start

# Остановить бота
POST http://localhost:8080/api/bots/bot1/stop

# Получить статистику
GET http://localhost:8080/api/stats

# Список прокси
GET http://localhost:8080/api/proxies
```

### WebSocket для real-time

Подключиться к WebSocket:
```
ws://localhost:8080/api/ws?api_key=ваш-ключ
```

События:
```json
// Бот изменил статус
{"type": "bot_status_changed", "payload": {"bot_id": "bot1", "status": "running"}}

// Бот отправил сообщение
{"type": "bot_message_sent", "payload": {"bot_id": "bot1", "message": "Привет!"}}

// Обновилась статистика
{"type": "stats_updated", "payload": {"total_bots": 5, "running_bots": 3}}
```

## Безопасность

⚠️ **Важно:**

1. **Не публикуйте OAuth токены** - это пароли от ваших Twitch аккаунтов
2. **Используйте сильный API_KEY** - это защита веб-панели
3. **Не коммитьте .env файлы** - там секретные данные
4. **Используйте прокси** - чтобы Twitch не забанил всех ботов сразу

## Для production (реальное использование)

Если хотите использовать на постоянной основе:

1. **Используйте облачный AI** (Omniroute) - не нужен мощный компьютер
2. **Настройте прокси** - защита от банов
3. **Используйте сильный API_KEY** - минимум 20 символов
4. **Отключите консоль** - `ENABLE_CONSOLE=false`
5. **Соберите frontend** - `cd frontend && npm run build`
6. **Запускайте через systemd/supervisor** - автоматический перезапуск
