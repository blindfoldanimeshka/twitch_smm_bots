# 🔤 ОБНОВЛЕНИЕ ШРИФТОВ - ЕДИНЫЙ ГЕОМЕТРИЧЕСКИЙ СТИЛЬ

## Проблема

**Было**: 
- Английский: Orbitron (квадратный, геометрический, угловатый)
- Русский: Rajdhani (кругловатый, мягкий)
- **Несоответствие стилей** - английский выглядел tech/cyber, русский - обычный

## Решение

**Стало**:
- Display (заголовки, кнопки): **Orbitron** + **Exo 2**
- Body (основной текст): **Exo 2**
- Mono (код): **JetBrains Mono**

### Почему Exo 2?

**Exo 2** - это геометрический sans-serif шрифт с полной поддержкой кириллицы:

✅ **Геометрический** - квадратные формы, как у Orbitron  
✅ **Кириллица** - полная поддержка русского языка  
✅ **Tech-стиль** - футуристичный, современный  
✅ **Угловатый** - острые углы, не округлый  
✅ **Вариативность** - 9 начертаний (400-900)  
✅ **Google Fonts** - бесплатный, быстрая загрузка

## Изменения в коде

### 1. Импорт шрифтов
```css
/* Было */
@import url('...Rajdhani...');

/* Стало */
@import url('...Exo+2:wght@400;500;600;700;800;900...');
```

### 2. CSS Variables
```css
/* Было */
--font-display: 'Orbitron', 'Rajdhani', sans-serif;
--font-body: 'Rajdhani', sans-serif;

/* Стало */
--font-display: 'Orbitron', 'Exo 2', sans-serif;
--font-body: 'Exo 2', sans-serif;
```

### 3. Font Weight
```css
/* Увеличен базовый вес для лучшей читаемости */
body {
  font-weight: 600; /* было 500 */
}
```

- Только одно начертание

## Производительность

### Размер загрузки
- **Rajdhani**: ~45KB (4 начертания)
- **Exo 2**: ~65KB (6 начертаний)
- **Разница**: +20KB (~0.02MB)

### Оптимизация
```css
/* Загружаем только нужные начертания */
@import url('...Exo+2:wght@400;500;600;700;800;900...');

/* Используем display=swap для быстрой загрузки */
&display=swap
```
