**Файлы для изменения:**
- `internal/api/handlers.go` - добавить валидацию в CreateBot
- `internal/twitch/helix.go` - использовать Helix API для проверки
- `frontend/src/hooks/useBotForm.ts` - добавить проверку формата логина

**План:**

#### 3. Обработка Twitch Rate Limits (420 error)
**Проблема:** При превышении лимитов Twitch возвращает ошибку 420  
**Решение:**
- Отлавливать ошибку 420 в IRC клиенте
- Реализовать exponential backoff для повторных попыток
- Приостанавливать бота на время cooldown

**Файлы:**
- `internal/twitch/irc.go` - обработка 420 ошибки
- `logic.go` - логика повторных попыток

**План:**
1. В `handlePRIVMSG` или аналогичном методе проверять ответ сервера
2. При получении "420" - ждать 30 секунд + exponential backoff
3. Логировать в bot_logs с типом 'rate_limit'
4. Уведомлять через WebSocket о приостановке

---

#### 4. Улучшенная обработка ошибок подключения
**Проблема:** Бот может "зависнуть" при потере соединения  
**Решение:**
- Реализовать переподключение с exponential backoff (уже есть в планах)
- Максимальное количество попыток (например, 5)
- Уведомление пользователя через WebSocket

**Файлы:**
- `internal/twitch/irc.go` - Reconnect() с логикой повторов
