## 🎪 Новые визуальные элементы

### 1. Фоновая киберсетка
- Сетка 20x20px по всему экрану
- Цвет: rgba(57,255,106,0.12)
- Opacity: 0.4
- Fixed position

### 2. Пиксельные углы на карточках
```
┌─────────────┐
│ CARD        │
│             │
└─────────────┘
```
- 4x4px квадраты в углах
- Неоновое свечение
- Цвет: #39FF6A

### 3. Неоновое свечение
- box-shadow: 0 0 8px rgba(57,255,106,0.55), 0 0 24px rgba(57,255,106,0.25)
- Применяется к:
  - Активным кнопкам
  - Границам карточек
  - Статус индикаторам
  - Заголовкам

### 4. Анимация "световой волны" на кнопках
```css
btn::before {
  background: linear-gradient(90deg, transparent, rgba(255,255,255,0.2), transparent);
  animation: sweep on hover;
}
```

### 5. Последовательное появление контента
- Каждый элемент появляется с задержкой 60ms
- Fade in + slide up эффект
- Создаёт ощущение "загрузки системы"

## 🎬 Анимации и переходы

### Timing
- Fast: 120ms (hover states)
- Base: 180ms (transitions)
- Slow: 260ms (complex animations)
- Easing: cubic-bezier(0.2, 0.8, 0.2, 1)

### Типы анимаций
1. **fadeIn** - Появление контента
2. **slideIn** - Toast уведомления
3. **pulse** - Индикаторы статуса
4. **shine** - Световая волна на кнопках
