# Автоматическая инициализация LM Studio

## Что было добавлено

### Backend (Go)

**Файл: `internal/llm/lmstudio.go`**

Добавлена автоматическая инициализация LM Studio при создании клиента:

1. **`autoInitializeLMStudio()`** - запускается в фоне при создании клиента
   - Проверяет доступность LM Studio
   - Получает список доступных моделей
   - Автоматически выбирает первую модель, если не указана
   - Проверяет, загружена ли модель
   - Загружает модель при необходимости

2. **Вспомогательные методы:**
   - `checkLMStudioAvailable()` - проверка доступности LM Studio
   - `getAvailableModels()` - получение списка моделей
   - `isModelLoaded()` - проверка загрузки модели
   - `loadModel()` - загрузка модели

3. **Улучшенное логирование:**
   - `[LLM]` префикс для всех сообщений
   - Информация о статусе инициализации
   - Подсказки при ошибках

## Как это работает

1. При запуске приложения создается LLM клиент
2. Если провайдер = "lmstudio", запускается автоинициализация в фоне
3. Проверяется доступность LM Studio на `http://127.0.0.1:1234/v1`
4. Если LM Studio запущен:
   - Получается список моделей
   - Выбирается первая доступная модель (если не указана)
   - Проверяется загрузка модели
   - При необходимости модель загружается автоматически

## Логи при старте

```
[LLM] Initializing client: provider=lmstudio, model=, url=http://127.0.0.1:1234/v1
[LLM] Auto-selected model: llama-3.2-3b-instruct
[LLM] Model llama-3.2-3b-instruct already loaded
[LLM] Client ready: provider=lmstudio, model=llama-3.2-3b-instruct
```

Или при ошибке:
```
[LLM] LM Studio not available: LM Studio not running on http://127.0.0.1:1234/v1
[LLM] Make sure LM Studio is running on http://127.0.0.1:1234/v1 with a model loaded
```

## Что нужно сделать пользователю

1. Запустить LM Studio
2. Скачать любую модель (например, llama-3.2-3b-instruct)
3. Запустить сервер в LM Studio (кнопка "Start Server")
4. Запустить TwitchSMM - модель загрузится автоматически

## Преимущества

- ✅ Не нужно вручную загружать модель в LM Studio
- ✅ Автоматический выбор первой доступной модели
- ✅ Понятные сообщения об ошибках
- ✅ Работает в фоне, не блокирует запуск
- ✅ Совместимо с другими провайдерами (OpenRouter, OpenAI)
