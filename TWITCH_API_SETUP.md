# Настройка Twitch API для получения категории/игры стрима

Боты теперь могут получать информацию о текущей категории стрима и игре, в которую играет стример. Это позволяет генерировать более релевантные сообщения.

## Как получить Twitch Client ID и Client Secret

1. Перейдите на https://dev.twitch.tv/console/apps
2. Войдите в свой Twitch аккаунт
3. Нажмите "Register Your Application"
4. Заполните форму:
   - **Name**: Любое название (например, "My Bot App")
   - **OAuth Redirect URLs**: `http://localhost` (можно указать любой URL, для этого приложения не важно)
   - **Category**: выберите "Application Integration" или "Chat Bot"
5. Нажмите "Create"
6. После создания приложения нажмите "Manage"
7. Скопируйте **Client ID**
8. Нажмите "New Secret" и скопируйте **Client Secret** (он показывается только один раз!)

## Настройка через UI

1. Откройте веб-интерфейс бота (обычно http://localhost:3000)
2. Перейдите в раздел **Settings**
3. Найдите поля **Twitch Client ID** и **Twitch Client Secret**
4. Вставьте скопированные значения
5. Нажмите **Save Settings**

После сохранения настроек Twitch Helix API клиент будет автоматически инициализирован, и боты начнут получать информацию о категориях стримов.

## Что это дает

Когда боты генерируют сообщения, они теперь получают дополнительный контекст для каждого канала:

- **Название игры/категории** (например, "Dota 2", "Just Chatting")
- **Название стрима** (title)
- **Статус стрима** (онлайн/оффлайн)
- **Количество зрителей**

Этот контекст передается в LLM вместе с промптом, что позволяет генерировать более релевантные сообщения для каждого конкретного канала.

## Пример

Если стример играет в Dota 2, бот может написать что-то связанное с игрой, а не просто общие фразы. Если бот работает на нескольких каналах одновременно, он будет получать информацию о категории для каждого канала отдельно.

## Опционально

Если вы не настроите Twitch API (не укажете Client ID и Secret в Settings), боты будут работать как раньше - просто без информации о категории стрима.

## Проверка работы

После сохранения настроек в логах бэкенда должна появиться строка:
```
Twitch Helix API client initialized from settings
```

## Миграция базы данных

При первом запуске после обновления автоматически будут добавлены новые поля в таблицу `settings`:
- `twitch_client_id`
- `twitch_client_secret`

Миграция происходит автоматически при старте приложения.
